## Iron Meridian - download and play

Offline single-player RTS: **Advanced Coalition vs Iron Dominion** with base building,
harvesting, armies, aircraft, a navy on water maps, engineers, AI opponents and developer tools.
Pick one of **10 countries** by flag (USA, UK, Germany, France, Thailand, South Korea, Japan,
Russia, China, Cuba), each with its own unique unit, power or bonus and infantry uniform.

| System | Download |
| --- | --- |
| Windows 10/11 (64-bit) | **IronMeridian-Windows.zip** - unzip, run `IronMeridian.exe` |
| macOS 10.12+ (Intel and Apple Silicon) | **IronMeridian-macOS.zip** - unzip, right-click the app > Open |
| Linux (64-bit) | **IronMeridian-Linux.zip** - unzip, run `IronMeridian.x86_64` |

Windows may show "Windows protected your PC" because the game is not code-signed:
click **More info > Run anyway**. Instructions are in `README-PLAYERS.txt` inside the zip.

This release is rebuilt automatically from the latest source.
