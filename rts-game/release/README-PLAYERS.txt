IRON MERIDIAN - offline real-time strategy
==========================================

WINDOWS
  1. Unzip IronMeridian-Windows.zip (right-click > Extract All).
  2. Double-click IronMeridian.exe.
  3. If Windows shows "Windows protected your PC", click "More info" > "Run anyway".
     (The game is not code-signed; that warning appears for any unsigned program.)

LINUX
  Unzip, then run ./IronMeridian.x86_64 (make it executable with chmod +x if needed).

MACOS
  Unzip IronMeridian-macOS.zip, then right-click "Iron Meridian" > Open > Open.
  (The app is not notarized, so the first launch needs right-click > Open.)

HOW TO PLAY
  - Select the construction vehicle and press E to deploy your base.
  - Build a Power Plant, then an Ore Refinery, Barracks and War Factory from the right sidebar.
  - Destroy every enemy structure to win.
  - Skirmish > Water: Coastal gives maps with sea for naval yards and fleets.

CONTROLS
  Left drag: select    Right click: move / attack    Q: attack-move
  Ctrl+1-9: control groups    Mouse wheel: zoom    F9: pause    Esc: menu (save/load)
  F10: developer tools (cheats; allowed in Sandbox or when enabled in Skirmish setup)

No internet connection is needed. Saves are kept in your user folder.
If the screen is black or the game will not start on an old PC, update your graphics driver.
